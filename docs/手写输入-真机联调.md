# MemeBoard 手写输入（阶段 3：gpen 桥接）真机联调说明

## 产物（均位于 dist/，全部 arm64-v8a）

| 文件 | 作用 | 大小 |
|------|------|------|
| fcitx5-memeboard-arm64-debug.apk | MemeBoard 主程序（含手写 UI + AIDL 客户端） | ~62 MB |
| fcitx5-rime-arm64-debug.apk | 拼音插件（万象词库 + 语法模型，阶段 1 产物） | ~420 MB |
| gpen-bridge-arm64-debug.apk | 语燕手写桥接（搜狗手写引擎 + AIDL 服务） | ~17.5 MB |

> 注意：gpen-bridge 的包名为 com.yuyan.pinyin.offline.release（语燕 SDK 授权绑定的包名之一），
> 不要与已安装的语燕输入法 offline release 版同时安装，否则包名冲突。

## 安装（真机，必须 arm64）

```bash
adb install -r dist/fcitx5-memeboard-arm64-debug.apk
adb install -r dist/fcitx5-rime-arm64-debug.apk
adb install -r dist/gpen-bridge-arm64-debug.apk
```

## 配置

1. 系统设置 → 语言和输入法 → 启用并选择「Fcitx5」。
2. MemeBoard 设置 → 虚拟键盘 → **空格键长按行为 → 手写输入（gpen 桥接）**。
3. （拼音）确认 rime 插件已加载、万象拼音可选。

## 使用

- 在任意输入框**长按空格键** → 键盘区变为手写板。
- 手写板区域写字（支持多笔连写），每抬一笔即识别，候选显示在顶部候选栏。
- 点候选 → 上屏并清空手写板，继续写下一个字。
- 底部三个键：**清空**（清笔迹与候选）、**⌫**（退格）、**退出**（返回键盘）。

## 排障

手写识别在桥接进程内执行，日志 TAG：

- 桥接 APK：`GpenBridge`（初始化/识别）
- MemeBoard 端：`GpenLink`（绑定/识别调用）

```bash
adb logcat -s GpenBridge GpenLink
```

关键状态：
- 长按空格后若弹出「手写引擎不可用: xxx」，说明桥接 APK 初始化失败（多为搜狗授权/包名/so 加载问题）。
- `engine status: ok` 表示引擎就绪。

## 已知风险（真机首次验证重点）

1. **搜狗 SDK 联网授权**：gpen 引擎内置 SogouAuth 计数授权（`SogouAuth_CheckCountLimit` / `checkCountLimitFromServer`），
   首次可能需联网校验，或存在每日识别次数上限。这是闭源 SDK 行为，无法离线预判。
2. **包名授权**：桥接 APK 已用授权包名 com.yuyan.pinyin.offline.release，理论上能通过本地包名校验。
   若仍被拦，logcat 会显示 GpenBridge 的 engine status 非 ok。
3. 若手写始终无候选，先看 `engine status` 是否为 ok；再确认桥接 APK 已安装、未被系统限制自启动/后台。

## 架构

MemeBoard（手写 UI：采集笔画 + 贝塞尔绘制 + 候选上屏）
    │  AIDL: IHandwritingService.recognize(int[] points)
    ▼
gpen-bridge（com.yuyan.pinyin.offline.release）
    │  JNI: com.yuyan.inputmethod.core.HandWriting
    ▼
搜狗手写引擎（libhandwriting.so + libgpen_handwriter.so + libhwInterface.so + libSogouShell.so）
